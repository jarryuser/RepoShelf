## Огляд

RepoShelf сканує вибрану папку та збирає локальні Git-репозиторії на одній панелі

Одразу видно, де залишилися незакомічені зміни, яку гілку відкрито та який коміт був останнім. Для кожного проєкту можна зберегти команду запуску, відкрити редактор і переглянути вивід процесу

Застосунок працює локально, не потребує облікового запису та не надсилає вміст репозиторіїв на сервер

## Початок роботи

Потрібні Node.js 20.19+ або 22.12+, npm, актуальний стабільний Rust і Git у PATH, а також [системні залежності Tauri](https://v2.tauri.app/start/prerequisites/)

На macOS установіть Command Line Tools, якщо їх ще немає:

```bash
xcode-select --install
```

Із папки проєкту:

```bash
npm install
npm run desktop
```

Під час першого запуску Cargo завантажить і збере Rust-залежності

1. Натисніть **Вибрати папку** та вкажіть директорію з проєктами
2. Виберіть репозиторій, щоб побачити гілку, останній коміт і змінені файли
3. Виберіть виявлену команду проєкту або введіть власну, наприклад `npm run dev`, `cargo run` чи `python3 app.py`
4. Натисніть **Запустити проєкт** і відкрийте вкладку **Логи**

Виявлення команд лише читає файли проєкту та нічого не запускає. Вибір команди заповнює поле; для виконання натисніть **Запустити проєкт**

Команда зберігається під час запуску; її також можна зберегти окремо кнопкою з галочкою або клавішею Enter

### Перегляд змін

На вкладці **Зміни** натисніть на файл, щоб відкрити diff

- **Робоча папка** показує зміни відносно індексу та вміст невідстежуваних файлів
- **В індексі** показує зміни, підготовлені до коміту
- Перейменовані файли зберігають початковий і новий шлях
- Кнопка оновлення перечитує diff, Escape закриває вікно

Відкритий diff оновлюється разом із репозиторієм при зміні файлів. Перегляд не змінює файли та індекс; розмір обмежено 256 КіБ або 4000 рядками

### Попередній перегляд у браузері

```bash
npm run dev
```

Відкрийте `http://127.0.0.1:1420`, щоб переглянути інтерфейс із демонстраційними даними

Доступ до папок, відкриття редактора та запуск команд доступні в desktop-застосунку

### Збирання

```bash
npm run build
npm run tauri -- build
```

Перша команда збирає інтерфейс у `dist/`, друга створює виконуваний файл застосунку в `src-tauri/target/release/`

Створення інсталяторів поки вимкнено через `bundle.active` у конфігурації Tauri

## Редактор і команди запуску

Відкрийте налаштування кнопкою на бічній панелі або сполученням `⌘ ,` / `Ctrl ,`

| Редактор | Команда в PATH |
|---|---|
| Visual Studio Code | `code` |
| Cursor | `cursor` |
| Zed | `zed` |
| IntelliJ IDEA | `idea` |

Для VS Code на macOS відкрийте палітру команд і виконайте `Shell Command: Install 'code' command in PATH`

Команди проєкту виконуються в каталозі репозиторію через `/bin/sh -c` на macOS/Linux або `cmd /C` на Windows. Доступні інструменти та змінні середовища успадковуються від процесу RepoShelf

Одночасно можна запускати кілька проєктів, по одному процесу на репозиторій. Перед зміною робочої папки потрібно зупинити запущені проєкти

Кнопка зупинки завершує дерево процесу на Windows і групу процесів на macOS/Linux. Під час виходу із застосунку керовані процеси також завершуються

## Архітектура

```text
React / TypeScript
    |
    | Tauri invoke
    v
Rust
    |-- walkdir -> репозиторії та worktree
    |-- git CLI -> статус, гілка, коміт, upstream
    |-- notify -> події зміни файлів -> оновлення панелі
    |-- процеси -> stdout / stderr -> події логів
    '-- settings.json -> робоча папка, команди, редактор, історія
```

Сканування, відкриття редактора та запуск команд виконуються поза основним потоком вікна. Вивід процесів читається окремими потоками

Інтерфейс використовує вбудований API Tauri через `withGlobalTauri`; JavaScript API постачається разом із Rust-частиною застосунку

Git викликається з `--no-optional-locks`, щоб читання статусу не створювало зайвих блокувань індексу

Налаштування зберігаються в системній папці конфігурації застосунку `dev.reposhelf.desktop`, шлях визначає Tauri. Запис відбувається через тимчасовий файл і перейменування

## Перевірки

```bash
npm run check
npm run test:ui
npm run test:rust
cargo fmt --manifest-path src-tauri/Cargo.toml --check
```

Тести інтерфейсу запускають зібраний застосунок у jsdom і перевіряють пошук, фільтрування, вибір проєкту, налаштування, гарячі клавіші, вибір команд, відновлення запущених процесів після перезавантаження інтерфейсу, перемикання джерел diff, номери рядків, обробку помилок та обмеження браузерного режиму

Rust-тести створюють тимчасові Git-репозиторії та перевіряють порожню історію, невідстежувані й змінені файли, коміти, перейменування з пробілами, worktree, виключення каталогів залежностей, виявлення команд, stdout/stderr, код завершення, зупинку дочірніх процесів і читання diff для нових, перейменованих, видалених та бінарних файлів

## Обмеження MVP

- Одна робоча папка за раз; команди та історія зберігаються при її зміні
- Обхід обмежений 5 рівнями та не переходить за символічними посиланнями
- Вкладені репозиторії та submodule всередині іншого репозиторію окремо не відображаються
- Каталоги `.git`, `node_modules`, `target`, `.venv`, `dist` і `vendor` виключені з обходу
- Немає операцій commit, push, pull і перемикання гілок
- Diff обмежений 256 КіБ або 4000 рядками; для бінарних файлів відображається повідомлення без текстового вмісту
- Diff відображає текст у UTF-8; некоректні послідовності байтів замінюються символом заміни
- Інсталятори, підписування застосунку та автоматичні оновлення не налаштовані
- Перегляд логів показує текст без емуляції TTY; інтерактивні команди не підтримуються
- Логи зберігаються в пам'яті, керівні послідовності термінала не інтерпретуються
- Показники ahead/behind обчислюються за локальним upstream без автоматичного fetch
- Команди, що створюють окрему сесію та від'єднуються від батьківського процесу, можуть продовжити роботу після зупинки проєкту
- Інтерфейс застосунку поки російською мовою; переклади README не змінюють мову інтерфейсу
